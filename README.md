# Nawaf HQ

Interactive AI company operating system for Nawaf. The dashboard is a static, free-to-host first phase with browser persistence through `localStorage` and a centralized state model in `dist/app.js`.

## Current capabilities

- Interactive isometric AI office with department entry points
- Editable AI employees with one shared source of truth
- Persisted company state, decisions, activities, projects, and task progress
- Live task simulation that updates employee status and activity
- Arabic RTL desktop and mobile layout

Future integrations are intentionally kept separate from the interface and can be connected through adapters without replacing the shared model.

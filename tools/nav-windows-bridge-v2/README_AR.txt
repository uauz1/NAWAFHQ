NAV Windows Bridge v2

وش يسوي:
- يربط ناڤ الموجود داخل NAWAF HQ بجهاز ويندوز محليًا.
- فتح البرامج والروابط.
- جلب البرنامج للواجهة.
- كتابة نص داخل برنامج محدد.
- اختصارات آمنة مثل Enter و Ctrl+L و Ctrl+S.
- نقر بالماوس بإحداثيات عند الحاجة.

التشغيل:
1) شغّل start-nav-bridge.bat
2) أول تشغيل ينشئ bridge-token.txt ويعرض الرمز في النافذة.
3) افتح ناڤ داخل NAWAF HQ واضغط «ربط».
4) الصق الرمز مرة واحدة.

الأمان:
- يستمع فقط على 127.0.0.1 وليس على الشبكة.
- كل أمر يحتاج رمز الربط.
- لا يوجد تنفيذ PowerShell أو Shell عام من ناڤ.
- البرامج المسموحة محددة داخل الجسر.
- الكتابة لا تضغط Enter تلقائيًا، لتقليل الإرسال غير المقصود.

أمثلة بعد الربط:
- افتح واتساب
- افتح VS Code
- ركز على كروم
- اكتب السلام عليكم في واتساب
- اضغط انتر في VS Code
